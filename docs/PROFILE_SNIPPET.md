# Profile-README snippet

Drop the markdown below into `bettyguo/bettyguo`'s profile README (the special
"profile repo" GitHub renders on your user page) to surface the AI-engineer
canonical set as a constellation.

```markdown
### Open roadmaps & references for AI engineers

I curate a constellation of standalone, citable artifacts for the AI-engineer
career path. Each is independently maintained; open the one that matches what
you're trying to do.

| Repo | What it is | Open when |
|---|---|---|
| **[ai-engineer-roadmap](https://github.com/bettyguo/ai-engineer-roadmap)** | The whole-field breadth roadmap, end to end, interactive. | "Where does this fit in the picture?" |
| **[harness-engineer-roadmap](https://github.com/bettyguo/harness-engineer-roadmap)** | The depth roadmap for the Agents & Harnesses stage. | "I want to specialize in building harnesses." |
| **[llm-interview-prep](https://github.com/bettyguo/llm-interview-prep)** | AI-engineer interview preparation. | "I am about to interview." |
| **[build-your-own-ai](https://github.com/bettyguo/build-your-own-ai)** | Hands-on "build it yourself" companion. | "I learn best by building." |

These are peers, not parent-and-children. Maintained on a monthly pulse +
weekly automated link-check.
```

The wording matches `roadmap-data/peers.json` and the README footers across
the four repos so a reader sees the constellation framed identically no
matter which artifact they land on first.
